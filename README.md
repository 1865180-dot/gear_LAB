# 歯車ラボ（gear_LAB）

中学校技術科「エネルギー変換の技術」で使う、歯車のかみ合いを学ぶブラウザ教材です。
テック未来の電気自動車模型（速い車・坂を登る車）製作の事前学習として、2時間で使う想定です。

## 内容

1. **実験室**：平歯車を2個→3個→4個→2段歯車とつなぎ、回る向き・速度伝達比・トルク（N·mとおもり何個分）を調べる（6ステップ）
2. **歯車図鑑**：かさ歯車、ラックとピニオン、ウォームギヤ、遊星歯車、プーリーとベルト、チェーンとスプロケット、内歯車、はすば歯車（8種類）
3. **チャレンジ**（全9問）
   - 問題1 自転車のギア（平地で速く／坂を登る／途中で変速）
   - 問題2 向きを変える（遊び歯車／かさ歯車／ラックとピニオン）
   - 問題3 遊園地のアトラクションを動かす（盤面に歯車をはめて、観覧車・メリーゴーランドへ動力を伝える）
4. **まとめ**

## 使い方

`index.html` 1ファイルで動きます。GitHub Pages を有効にすると、Chromebook のブラウザからそのまま開けます。
進みぐあいは各端末のブラウザに保存されます。
